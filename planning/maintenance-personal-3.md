# VoiceInk personal.3 维护交接

2026-11-13，用户确认：目标编辑框占位符为“发送消息”，不做任何手工修正、直接发送后，Auto Learn 仍建议把完整原句改为“发送消息”。本次针对这个可证缺陷修复，不把它混同 personal.2 已修复的 Ollama 服务选择问题。

## 改动

- Auto Learn 保存捕获目标的编辑器身份，在最终快照中确认元素仍可编辑且身份未改变，拒绝控件复用。
- 将最终文本与捕获时及最终时的 AXPlaceholderValue 比较，忽略空白、零宽等表示差异。相同则不产生更正；明确零字符的输入框却返回非空 UI 内容也不作为更正。
- 不硬编码“发送消息”或任何语言提示词。真实手工修改为恰好与占位文本完全相同的字符串时，保守跳过学习，但不改变用户输入或发送。
- 在原目标元素订阅 AXValueChanged，保存已实际读取到的有效修改；发送清空或显示占位时仍可使用该修改。观察到撤销回原文则清空候选，身份变化则作废会话。首次清空/占位后封存候选，避免同一输入框下一条消息被误当作上一条的更正。
- 中文标点成为候选上下文边界；含汉字片段采用系统词级分词，不再把整段无空格文本当一个词。限制候选词数、长度，并拒绝单个汉字的全局替换建议。英文原有分段与词形过滤保留。
- AI 审核提示不再限定仅英语，保留同一实体/专业词纠正、拒绝改事实和不同实体的规则，禁止翻译；现有英语审核批准仍适用。未调用真实远端模型做推断效果验收。
- 不扩大观察窗口，不添加键盘监听或新权限，不改个人模式、中文 V3 提示词和远端配置。
